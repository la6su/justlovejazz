The Vision

This project serves as a playground for Three.js TSL and WebGPU, pushing the boundaries of real-time procedural graphics in the browser.

By leveraging the latest GPU technologies, we can create experiences that were previously impossible in a web browser.

The central object and background react to your movements, creating a symbiotic relationship between the user and the digital space.

Every interaction is designed to be fluid, responsive, and visually captivating.
