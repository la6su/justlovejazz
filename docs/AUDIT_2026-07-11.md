## 3. Architecture summary

### 3.1 Six sections × six cube faces

The codebase unified around a 6-section model where each section index maps
1:1 to a cube face. SplashCube rotates per section to show the active face;
the BakuCarousel on Works (idx 3) morphs the back face into a ring.

| Idx | Section | Cube face | Theme | 3D content |
| --- | --- | --- | --- | --- |
| 0 | Lab (secret left) | Top (+Y) | light | `makeParticles` |
| 1 | Intro (start) | Front (+Z) | light | SplashCube + particles |
| 2 | About | Right (+X) | dark | Particles + WireframeTypography |
| 3 | Works | Back (-Z) | dark | BakuCarousel + DrawTrail + particles |
| 4 | Contact | Bottom (-Y) | light | Particles |
| 5 | Process (secret right) | Left (-X) | dark | `makeParticles` |

Light sections (0, 1, 4) toggle `uk-light` body class via ThemeManager.
World starts on section 1 (Intro), EnvSphere starts on `[0,1,0,0,0,0]` weights.

### 3.2 UIKit3 native theme system

The custom `body.light-theme .uk-*` override system (50+ LOC of dead CSS) was
replaced with UIKit's native `uk-light` inverse class:

- `_import.less`: `@inverse-global-color-mode: light` generates `uk-light` class
- `ThemeManager.ts`: 3 modes (auto/light/dark), localStorage persistence, `jlz:theme-applied` event
- 1 class on `<body>` flips ALL UIKit components natively (headings, text, buttons, cards, navbar)
- Custom non-UIKit elements (joystick, hint, brand, corner-label) still keyed on `body.uk-light, body.light-theme` (synonym)
- 3D EnvSphere syncs to manual override (light forced → Intro pattern, dark forced → About pattern)

### 3.3 Mobile-first rem sizing

All sizing is rem-based, driven by a mobile-first root font-size:

- `html { font-size: 0.85rem }` mobile → `1rem` ≥640px (in `main.less`)
- 76 px values in `master-quantum-flares/_import.less` converted to rem
- 7 hairline borders (1-3px) kept as px for crispness
- UIKit globals (`@global-margin`, `@global-gutter`, `@global-control-height`, etc.) all rem-based
- Responsive sections: `uk-section-small uk-section-medium@s uk-section-large@m`

### 3.4 Tokens merge

`src/styles/tokens.less` was DELETED and merged into `src/assets/_import.less`:

- §1: `@jlz-*` design tokens (Less variables — color, typography, spacing, radius, z-index, motion)
- §2: `:root { --jlz-* }` CSS custom properties (runtime `var()` usage)
- §3: UIKit variable overrides (map `@jlz-*` → UIKit `@*`)
- §4: UIKit component imports (order-dependent)

`master-quantum-flares/_import.less` no longer duplicates UIKit globals — it
only adds QF visual personality (font weights, status colors, box-shadows,
glitch/scanline effects). `src/styles/` directory removed.

### 3.5 Cube face rotation per section

Each section index maps to a cube face. `World.updateTransform()` rotates the
SplashCube so the active face points at the camera. BakuCarousel on Works
(idx 3) morphs the back face into a ring (cube→ring transition via `morphT`
0→1, driven by `setActive(fade>0.5)` in `updateTransform`).

### 3.6 BakuCarousel on Works (idx 3)

Two race conditions were fixed in commit `63c3729`:

1. `World.ts` line 180 referenced `sceneGroups[4]` (now Contact) — fixed to `[3]`
2. `Experience.ts` `getCarousel()` referenced `sceneGroups[4]` — fixed to `[3]`
3. `Experience.ts` computed `_bakuCarouselActive` AFTER the `_needsRender`
   check, so on the frame when `setActive(true)` triggered, the stale `false`
   meant `world.update()` was skipped → `carousel.update()` never ran → `morphT`
   stalled at ~0.35. Moved `isAnimating` computation BEFORE `_needsRender` check.

Also fixed hardcoded section indices (cursorFollow idx===4→3, `Math.min(idx+1,
7)→5`, drawTrail `fromIndex===4→3`).
